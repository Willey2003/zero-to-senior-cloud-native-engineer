# Lab 14: Platform Engineering (Backstage, Crossplane, golden paths)

## Concepts (CNPA)
A **platform team** builds an **Internal Developer Platform (IDP)** so app teams can self-serve:
"I need a new service with CI/CD, a database, monitoring and a namespace", in minutes, safely, without tickets.
Key ideas: platform as a product, golden paths, self-service APIs, guardrails (policy as code), cognitive load,
DORA metrics (deploy frequency, lead time, change failure rate, time to restore), multi-tenancy, cost visibility.

## Part A: Backstage (CBA)
```bash
npx @backstage/create-app@latest     # needs Node.js LTS
cd my-portal && yarn start
```
- **Software Catalog**: register the lab API with `manifests/catalog-info.yaml` (Component, API, System, Group, User).
- **Software Templates** (`manifests/template.yaml`): a "New Python service" golden path that creates a repo with
  Dockerfile, CI, Kubernetes manifests and an Argo CD Application.
- **TechDocs**: docs-as-code from Markdown. **Plugins**: Kubernetes, Argo CD, GitHub Actions. Auth with GitHub.

## Part B: Platform APIs with Crossplane
Define an `XPostgresDatabase` composite: app teams ask for "a small Postgres" with a Claim; Crossplane creates RDS
(or a local Helm chart) with your security defaults. This is how platforms offer infrastructure as a Kubernetes API.

## Part C: Putting the IDP together (CNPE hands-on)
- Multi-tenancy: namespace-per-team with ResourceQuota, LimitRange, RBAC, default NetworkPolicy (generated by Kyverno).
- GitOps (Lab 12) as the delivery engine, Backstage as the front door, Crossplane for infra, Kyverno for guardrails,
  Prometheus/OTel for observability, OpenCost for cost.
- Measure DORA metrics from your pipeline.

## Real-world scenario
"Teams wait 2 weeks for a new environment." Build a template so a developer clicks once in Backstage and gets a repo,
pipeline, namespace, database and dashboard in 10 minutes. Write a one-page "platform product" doc: users, pain, metrics.

**Cert mapping:** CBA, CNPA, CNPE, KCA (policies from Lab 09).
